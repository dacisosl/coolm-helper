# 쿨 비서 Electron 프로젝트 — 수정본

요청하신 수정사항을 반영한 데스크톱 비서 프로젝트입니다.

## 반영된 수정사항

- 네 포즈 이미지를 투명 PNG로 다시 분리
- 캐릭터 주변에 산 배경이나 배경색이 남는 현상 완화
- Electron 창과 HTML 루트 배경을 완전 투명으로 강화
- 기본 포즈를 완전한 왼쪽 측면이 아닌, **왼쪽과 정면 사이의 3/4 방향**으로 변경
- 기본 / 수면 / 일정 정리 / 놀람 포즈 유지
- 30초 무조작 시 자동 수면
- 클릭으로 포즈 순환, 더블 클릭으로 놀람
- 숫자 키 1~4로 포즈 전환

## 실행 방법

Node.js LTS가 설치된 Windows에서 압축을 풀고 프로젝트 폴더의 터미널에서 실행합니다.

```bash
npm install
npm start
```

## Windows 실행 파일 만들기

```bash
npm run pack:win
```

완료되면 `dist` 폴더에 휴대용 실행 파일이 생성됩니다.

## 단축키

- `1`: 기본 포즈
- `2`: 수면 포즈
- `3`: 일정 정리 포즈
- `4`: 놀람 포즈
- 캐릭터 클릭: 다음 포즈
- 캐릭터 더블 클릭: 놀람 포즈

## 이미지 교체 규칙

향후 더 정교한 캐릭터 렌더를 만들 경우 아래 파일을 동일한 이름으로 교체하면 됩니다.

```text
app/assets/idle.png
app/assets/sleep.png
app/assets/schedule.png
app/assets/surprise.png
```

모든 파일은 투명 배경 RGBA PNG, 동일한 720×720 캔버스를 권장합니다.
