# COOL-비서 — 설치 안내

## 설치

1. `CoolmHelper-Setup.exe`를 실행하고 안내를 따르세요. (관리자 권한 불필요)
2. 설치 중 Windows SmartScreen이 "인식할 수 없는 앱" 경고를 띄울 수 있습니다.
   서명 없는 개인 제작 프로그램이라 나타나는 정상적인 경고입니다 —
   **추가 정보 → 실행**을 누르면 됩니다.
3. 첫 실행 시 쿨메신저 메시지함 위치를 자동으로 찾습니다
   (`%LOCALAPPDATA%\CoolMessenger\Memo`). 별도 설정이 필요 없습니다.

### 설치파일이 아예 막히는 컴퓨터라면 (압축본)

학교 PC의 백신이 설치파일 실행 자체를 막는 경우가 있습니다. 그럴 땐
릴리스에 함께 올라오는 **`CoolmHelper-Setup.zip`** 을 받으세요.
**같은 설치파일을 압축만 한 것**입니다 — 인터넷에서 바로 받은 exe에는
"외부에서 받음" 표시가 붙어 차단되지만, 압축을 풀어 나온 파일에는
그 표시가 붙지 않아 대부분 그냥 실행됩니다.

1. ZIP의 압축을 풉니다. (반디집·알집·탐색기 아무거나)
2. 나온 `CoolmHelper-Setup.exe`를 실행하고 안내를 따르세요.
3. 그 뒤는 위 설치 방법과 똑같습니다 — **새 버전 자동 업데이트도 그대로 됩니다.**

## 첫 사용

1. 화면 오른쪽에 펭귄(쿨쿠리)이 뜹니다. **끌어서 어디로든 옮길 수 있고**,
   모니터가 두 대면 **다른 모니터로도** 옮겨집니다. 놓아둔 자리는 기억돼요.
   자꾸 건드려 움직이는 게 싫다면 펭귄을 클릭 → **📌**를 누르면 그 자리에
   고정됩니다. (📌를 다시 누르면 풀려요.)
2. **[📅 일정 등록]** — 가장 최근 쪽지 10개에서 일정 후보를 찾아 보여줍니다.
   (창 위쪽에서 50개·100개로 늘릴 수 있습니다.)
   빨간 글씨는 전화번호·이름으로 보이는 부분입니다. 제목·일시를 확인/수정 후
   [등록]을 누르세요.
3. **[🗓 캘린더 / 할일]** — 등록한 일정을 월간 캘린더와 할일 목록으로 봅니다.
   인터넷 연결이 필요 없습니다.

## 학사일정 가져오기 (나이스)

우리 학교 학사일정을 손으로 옮겨 적지 않아도 됩니다.

1. 펭귄 클릭 → **🏫 학사일정**
2. 처음 한 번만 **학교 이름으로 검색**해서 우리 학교를 고릅니다. (그 뒤로는 기억해요)
3. 기간을 고르고 **[불러오기]** → 목록에서 필요한 것만 체크 → **[선택한 일정 등록]**

- 여러 날에 걸친 행사(수련회 등)는 **기간 일정 한 건**으로 합쳐서 들어갑니다.
- 이미 등록한 일정은 **✓ 등록됨**으로 표시돼 두 번 들어가지 않습니다.
- 나이스로 나가는 정보는 **학교 이름·학교 코드와 조회 기간**뿐입니다.
- 나이스 인증키는 프로그램에 들어 있어 **따로 넣지 않아도 됩니다.**
  "오늘 조회 한도를 넘었습니다"가 뜨면, 나이스에서 무료로 본인 키를 발급받아
  설정 → 데이터 → 나이스 인증키에 넣으면 그 PC는 한도를 따로 씁니다.
- 안 될 때는 설정 → 데이터 → **[연결 진단]** 을 눌러 보세요.

## 학생 명단 설정 (권장)

설치 폴더의 `students.txt.example`을 복사해 같은 위치에 `students.txt`로 저장하고,
우리 반 학생 이름을 한 줄에 하나씩 적으세요. 일정 제목에 학생 이름이 들어가면
자동으로 ○○○ 처리됩니다. 이 파일은 어디에도 전송되지 않습니다.

## 구글 캘린더 연동 (선택)

기본 기능은 구글 계정 없이 전부 동작합니다. 구글 캘린더에도 올리고 싶으면
`구글연동설정.md`를 참고하세요.

## 문제 해결

- "메시지 DB를 찾을 수 없습니다" → 쿨메신저가 설치·로그인되어 있는지 확인.
  경로가 다르면 설치 폴더 `config.json`의 `memo_dir`를 수정하세요.
- 쿨메신저 업데이트 후 동작하지 않으면: 쿨메신저 메시지 관리함에서 엑셀로
  내보내기 하면 프로그램이 자동으로 그 파일을 읽습니다(Plan B 모드).

## 삭제

제어판 → 프로그램 제거. 등록한 일정(`store/events.json`)과 학생 명단은
설치 폴더에 남으니 필요하면 삭제 전에 백업하세요.
